## 補足

- プロジェクトの追加は `apply-docs-structure` スキル（add-project）で行い、この一覧と `docs/index.md` を更新します。
- プロジェクトの成果物のレビューは `review/<project>/` に置き、プロジェクトの `index.md` で一覧を管理します。
- レビューは `analyzing-review`・`developing-review`・`developing-uiux-review`・`operating-review` スキルで行います。
