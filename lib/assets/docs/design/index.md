## 補足

- プロジェクトの追加は `apply-docs-structure` スキル（add-project）で行い、この一覧と `docs/index.md` を更新します。
- 実ドキュメントは `design/<project>/` に置き、プロジェクトの `index.md` で一覧を管理します。
- テンプレートは [template/設計.md](../template/設計.md) を利用できます。
